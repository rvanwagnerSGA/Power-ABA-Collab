The primary call-to-action control; always fully rounded (`--radius-pill`), never square-cornered.

```jsx
<Button variant="primary" size="lg">Get Started Today</Button>
<Button variant="outline" size="lg">Learn More</Button>
```

Variants: `primary` (red, one per view), `secondary` (indigo), `outline` (white with red hairline — the paired second CTA on hero units), `ghost`. Sizes `sm|md|lg`; heroes use `lg`. Hover lifts 2px and darkens; press scales to 0.97.
